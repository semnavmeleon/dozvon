# autodozvon

Автодозвон клиентов через IP-телефон Yealink (проверено на SIP-T30, прошивка 124.85.14.5).

Две базы загружаются в браузере: база 1 — источник номеров и основной информации, база 2 — результаты
колл-центра. Страница показывает клиента на весь экран, комментарий колл-центра и блок управления телефоном.
Телефон набирает номер по команде, а события звонка (начало, разговор, завершение, занято) возвращаются на страницу.
Результат обзвона пишется в базу 2, которую можно скачать.

Файлы никуда не отправляются: Excel читается прямо в браузере, а сервер только передаёт команды на телефон.

## Что умеет

* **Данные:** загрузка баз 1 и 2 (xlsx, xls, csv), выбор листа, ключа клиента и столбцов. Выбор запоминается в браузере.
* **Обзор базы:** таблица базы 1 с номерами строк Excel, статусом обзвона и комментарием колл-центра из базы 2. Фильтры «не обзвонены», «обзвонены», «с комментарием АКЦ», «без номера» и поиск по всем столбцам. Кнопка «Прозвон» начинает обзвон с выбранной строки по текущему списку. Порядок чтения ячеек взят из `macro-builder/excel-import.js`: телефоны в «Общем» формате не превращаются в `8,9E+10`.
* **Карточка клиента:** в первую очередь ФИО и телефон, затем ключевые данные (полис, сумма, срок, авто, регион, агент), комментарий колл-центра и остальные поля. Всё помещается в окно без прокрутки.
* **Телефон: полное управление** (вкладка «Телефон», без клиентской базы): набор номера, сброс, все клавиши телефона по группам (цифры, навигация, звонок, F1–F4, громкость, DND, линии и DSS), отправка любой разрешённой клавиши из списка, журнал событий.
* **Расширенный режим прозвона:** кнопка «Расширенный режим» в карточке прозвона показывает все поля клиента без скрытия, журнал всех событий телефона, все клавиши и сырые данные строки базы 1 и базы 2.
* **Статус звонка:** набор, разговор, завершён, абонент занят, абонент сбросил, таймер разговора.
* **Результат:** шесть кнопок (клавиши 1–6) записывают результат, дату и комментарий оператора в базу 2 и переводят на следующего клиента.
* **Сверка баз:** совпадения по ключу, только в базе 1, только в базе 2, расхождения в одинаковых столбцах. Списки можно скачать.

## Установка

```bash
cp config.example.ini config.ini   # укажите host (IP телефона) и порт сервера
export AUTODOZVON_PASSWORD='пароль-телефона'   # Windows PowerShell: $env:AUTODOZVON_PASSWORD='...'
```

Внешних зависимостей нет, нужен только Python 3.8+.

## Настройка телефона

1. Включите удалённое управление: **Features → Remote Control**, впишите IP компьютера в **Action URI Allow IP List** и нажмите Confirm.
   Первый запрос на телефоне нужно подтвердить кнопкой OK на экране «Allow Remote Control?».
2. Смените пароль `admin` в **Security**: в веб-интерфейсе висит предупреждение «Default password is in use».
3. **Features → Action URL**: в каждом поле, которое нужно отслеживать, укажите:

   ```
   http://IP_КОМПЬЮТЕРА:8000/<событие>?remote=$remote&local=$local
   ```

   Для основного обзвона нужны Outgoing Call, Established, Terminated, Remote Busy, Call Remote Canceled и Cancel Call Out. Остальные события (регистрация, DND, переадресация, перевод, удержание, гарнитура и т. д.) тоже принимаются и попадают в журнал.
   Имена `<событие>` совпадают с полями страницы в нижнем регистре с подчёркиваниями: `outgoing`, `established`, `terminated`, `remote_busy`, `remote_canceled`, `cancel_callout`, `registered`, `offhook`, `open_dnd` и т. д. Полный список скрипт печатает при запуске. Старые имена `busy`, `remotecanceled`, `cancelout` тоже принимаются.

## Запуск

```bash
python autodozvon.py
```

Откройте страницу: http://localhost:8000. Поле «Сервер на связи» вверху показывает, что скрипт работает.

Порядок работы:
1. Вкладка «Данные»: загрузить базу 1, выбрать ключ и столбец с телефоном. При необходимости загрузить базу 2 и выбрать столбец комментария.
2. Вкладка «Обзор базы»: выбрать фильтр, найти клиента и нажать «Прозвон» у нужной строки.
3. Вкладка «Сверка» (по желанию): проверить совпадения баз.
4. Прозвон на весь экран: клиенты идут по очереди. Клавиши: `1`–`6` — результат, `←` `→` — назад и дальше, `Esc` — выход к обзору.
5. «Скачать базу 2 с результатами» — сохранить итог. Без скачивания результаты пропадут при закрытии страницы.

## Как это устроено

| Файл | Что делает |
|---|---|
| `autodozvon.py` | Сервер: отдаёт страницу, пересылает команды на телефон (`servlet?key=number=...`, `servlet?key=<клавиша>`), принимает события Action URL |
| `index.html` | Интерфейс: загрузка и сверка баз, карточка клиента, управление звонком |
| `vendor/xlsx.full.min.js` | Библиотека SheetJS для чтения и записи Excel (лицензия в `vendor/LICENSE-xlsx.txt`) |
| `config.example.ini` | Пример настроек телефона и порта |
| `test_autodozvon.py` | Автотесты |

Пароль телефона хранится только в `config.ini` или переменной окружения, в браузер не передаётся.
`config.ini` в `.gitignore`.

## Клавиши телефона

Список клавиш взят из стороннего описания Action URI (`key=`) и на T30 не проверен, поэтому:
* `#` отправляется как `POUND`, громкая связь как `HANDFREE`: так назван ключ в описании Yealink.
* **Не добавлены** `Reboot` (перезагрузка) и `AutoP` (автопровижн): запуск этих команд с любого компьютера в сети опасен, и в интерфейсе их нет.
* Если клавиша на вашем T30 не срабатывает, проверьте её название в описании для вашей прошивки и поправьте `KEY_NAMES` в `autodozvon.py`.

## Ограничения

* Телефон не отличает ответивший человек от автоответчика, поэтому результат отмечает оператор.
* Голосовые сообщения клиенту не проигрываются, звонки идут по одному.
* Набор номера сейчас нормализуется как российский: 11 цифр с `+7` или `8` превращаются в `8XXXXXXXXXX`, 10 цифр получают `8` спереди.
  Если схема набора другая, поправьте функцию `toDialDigits` в `index.html`.
* События принимаются с любого адреса сети (телефон присылает их с собственного IP). Страница и управление телефоном доступны только с этого компьютера.

## Тесты

```bash
python -m unittest -v
```

Тесты используют локальную заглушку телефона с проверкой Basic-авторизации. Реальный телефон не нужен.

## Что проверено, а что нет

Автотесты проверяют чтение настроек, набор и сброс через заглушку телефона, белый список клавиш, события Action URL и ответ при недоступном телефоне.
Страница проверена в браузере на тестовых данных, без загрузки реального файла через диалог выбора.

**На живом Yealink T30 не проверено:** подстановка `$remote` и `$local` в Action URL и порядок событий при реальных звонках.
Первый запуск лучше сделать на своём номере: позвонить себе, занять номер, не поднять трубку, и посмотреть статусы на экране.
